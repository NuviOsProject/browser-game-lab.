Como o Nuvi Games Import funciona
  1. Importar: escolha arquivos do jogo no seu aparelho. A biblioteca é mantida durante a sessão desta página.
  2. HTML: um arquivo HTML autônomo pode ser aberto no player. Alguns jogos precisam de uma pasta inteira, recursos adicionais ou um servidor compatível.
  3. ZIP / JS / WASM: são identificados, mas não montados nem convertidos automaticamente por esta interface.
  4. EXE / ISO: não são HTML. Executá-los exige reimplementação do jogo, recompilação do código-fonte ou um runtime/emulador compatível. Não existe conversão universal sem erros.
  5. IA real: uma integração futura deve enviar apenas arquivos autorizados para um backend seguro, analisar o projeto, compilar/testar o resultado e informar claramente o que não foi convertido.

Privacidade: esta versão não faz upload de arquivos nem afirma realizar conversão por IA. Ela fornece a interface e a triagem inicial no navegador.
